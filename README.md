# libreNotes — downloads

Anotações desenhadas à mão e quadros infinitos para Linux (GTK 4 + libadwaita).

Site: https://librenotesapp.github.io/

## Baixar

**[Última versão](https://github.com/librenotesapp/librenotesapp.github.io/releases/latest)**: baixe o arquivo `libreNotes-<versão>-linux-x86_64.tar.gz`.

## Instalar (Linux x86_64)

```sh
tar xzf libreNotes-*-linux-x86_64.tar.gz
./libreNotes/install.sh
```

Depois procure por **libreNotes** no lançador de aplicativos. Não precisa de root.

- Atualizar: extraia a versão nova e rode o `install.sh` de novo.
- Desinstalar: `./libreNotes/install.sh --remove` (as notas são mantidas).
- Requisitos: GTK 4.20+ e libadwaita 1.8+.
